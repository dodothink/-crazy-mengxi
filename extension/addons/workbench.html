等待人工处理
已支持 /captcha 数学题推送到手机，由你回复答案；其他验证请在原浏览器完成。验证完成不会解除你手动设置的暂停，也不会自动重发结果不明的帖子。


本地服务与手机
服务地址固定为本机 127.0.0.1:17851。首次使用先完成配对，再填写下方连接设置。


Telegram 手机控制台
绑定后向机器人发送 /menu：查看状态、管理跟踪任务、修改与审核草稿、控制运行开关、查询发表记录。操作通常需等待一次或两次同步（约30–60秒），以机器人返回的执行结果为准。
手机草稿卡片点一次“批准并加入发帖队列”即可；按发帖间隔依次提交，无需等间隔到了再批准。输入 /queue 查看队列。原有“采用草稿”仍然只填入。电脑必须开机，Chrome、扩展及 Agent 保持运行。首次升级请重新加载扩展，再点击“同步状态”。
连接设置
每位使用者填写自己的密钥。留空保留原配置；保存后输入框清空，密钥只保存在本机 Agent。
连接本地服务后可配置
新用户可首次配置。已有机器人 Token 不在此覆盖，以保留原绑定和待办。


回复审核
草稿推送手机后不会倒计时发表。在 Telegram 阅读完整正文，点一次批准即可排队发送；电脑端可填入论坛回复框，由你点击发表。


Kimi 模型与用量
模型：Kimi K3.1 Pro，沿用原API Key。每日上限 0 表示不限；推理Token也计入输出预算。
跟踪任务管理
每个帖子是独立任务。添加新任务不会替换旧任务；停止旧任务请点击其卡片上的“暂停任务”或“移除任务”。
＋ 新建跟踪任务
每分钟只读本机存档；首次建立基线，之后成功采集的新回复才调用 Kimi（包含有效增量更新）。不会请求浏览器采集；没有本机数据时等待上游写入。每条草稿由你确认后发送。
跟踪回复默认立足你在帖内的发言，针对对方观点反驳或质疑，不默认附和。只反驳有依据的观点，不编造你的立场；立场不足或无需回应时跳过。每次参考你最近4条发言的节选。
原文引用会在回复里写出作者、楼层、最多240字原文及帖子链接；不是论坛原生引用框。不符合ID的楼层只作上下文，不触发拟稿。
没有符合筛选条件的任务，请切换筛选或清空搜索。
每轮分析楼层数和每日调用上限可在上方设置；超过单次正文预算会分批分析。已有草稿不会被覆盖，处理完请点“已处理 / 不回复”。暂停不会撤回已经提交的帖子。状态每5秒自动刷新，不调用Kimi；编辑内容不会被自动刷新覆盖。手动刷新前请保存草稿。
