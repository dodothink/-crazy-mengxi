# Telegram 任务管理 · agent.14.1

向已绑定的机器人发送 /menu 打开最新菜单。旧消息不会自动刷新。

新建：点「＋ 新建任务」（或 /new），发送帖子完整链接，再输入当前使用的论坛用户名，核对后点「确认」。首次只读取本机存档建立基线，之后的新楼层才拟稿；缺少存档时等待上游。重复任务直接显示现有任务，不会覆盖。

删除：点「删除任务」（或 /delete），选择帖子，核对标题、编号和链接后确认。删除会停止跟踪、清除任务草稿、取消未提交回复；存档和已发表回复保留。重新添加会重新建立基线。

新建中可点「取消新建」或发送 /cancel。显示「已排队」不等于成功，要等待电脑回报执行结果。电脑、Chrome和Agent须在线。仅原绑定的私人账号可操作。
