# Telegram 使用说明

## agent.8 Telegram 手机控制台

发送 /menu 或 /start 打开按钮菜单。仅限已绑定的私人账号。

- 状态面板：最近电脑同步时间、采集/发帖暂停、人工验证、任务数、Kimi当日调用（UTC日期）。
- 任务管理：查看任务、新建向导、暂停/恢复、二次确认移除、回复对象、原文引用开关、修改回复要求。
- 草稿审核：查看原楼层节选、修改完整正文、拒绝、二次确认实际发表。旧通知“采用草稿（仅填入）”仍不发表。
- 运行控制：暂停全部运行、恢复采集/发帖（确认）、暂停全部跟踪、开启自动发表（确认）、关闭、取消当前倒计时。
- 最近记录：公开接口返回的近期发表状态和手机指令执行结果；验证题仍由本人作答。

电脑、Chrome、Agent须运行，网络须可访问Telegram。/cancel退出当前输入，不撤回已经排队操作。新建输入与编辑10分钟过期，确认2分钟过期，排队指令90秒有效；离线或旧版扩展不接受新操作。一般30–60秒收到执行回报，“已排队”不等于“已完成”。

修改/拒绝会取消旧倒计时。实际发表再次核对任务、草稿、有效期、本人授权与论坛保护；被取消、暂停、已尝试或结果不明的回复不补发。已提交的回复不能撤回。同一草稿若已尝试自动发表，不允许手机重复发表，需先核对记录。

升级后重新启动Agent（本机部署由助手完成），在chrome://extensions重新加载疯狂的梦溪，关闭旧工作台重新打开并点击同步状态。原凭据与任务保留。首次安装、论坛登录、浏览器权限及部分验证仍需在电脑完成，TG不能替代这些步骤。
