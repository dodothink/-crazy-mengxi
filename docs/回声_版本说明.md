# 4.2.5-agent.15 — 纯文字提交与 TG 一键入队

本版仅修改下游梦溪·回声，不修改上游纯采集插件。保留任务、开关、存档路径、账号绑定和密钥。

## 修复

- TG 完整草稿卡片直接显示「批准并加入发帖队列」，一次点击就批准该条正文，不再弹二次确认。
- 已批准回复按先后顺序等待间隔与额度；授权有效期 24 小时，无需按时间逐条再次批准。发到一半中断或回执不明，不自动重试。
- /queue 或菜单「已批准队列」查看待发数与等待原因。修改正文、拒绝、暂停任务会使原授权失效；删除任务仍有确认。
- 已确认回复使用独立纯文字表单，仅提交经过核对的文字和必要表单字段，不调用原表单的提交事件，不继承附件；签名关闭，避免签名附图。发现附件字段、上传文件、富文本图片或正文图片标记则停止提交。
- 可靠发表回执使用该跟踪任务填写的本人用户名，避免依赖旧的全局用户名。
- 新通知展示完整正文，较长内容分段发送，批准按钮只放最后一段。旧通知可从 /menu → 待审草稿打开新版卡片。

## 问题调查的证据边界

已批准正文为纯文字；旧逻辑只核对正文，直接点击论坛原生提交按钮，没有隔离附件字段或编辑器提交处理。此漏洞已修复。历史请求没有完整网络载荷记录，因此不能断言本次截图到底来自附件残留、编辑器缓存还是其他页面状态。历史回执不明的那条回复保留原状态，不重发、不删除论坛内容。
