# 梦溪·回声 MENGXI ECHO

有所记录，有所回应。

当前版本 **5.0.0-merged.1**，原名“疯狂的梦溪”。一份代码两种角色：采集端读论坛写本机存档，回复端读存档、生成 AI 回复草稿、经 Telegram 审核后发表。上游基线 4.4.6，机读存档协议 v1，公共接口 1.2。

## 这版更新

- **合并上下游**：一份扩展代码，用「插件角色」区分采集端与回复端。
- **采集限频**：单页 20～30 秒随机，每小时上限 300 次；回复数与最后回复时间都没变就跳过。
- **风控熔断**：503 或验证页立即全局停止，15/30/60 分钟退避；面板提供「重试采集（已换 IP）」。
- **授权失效提醒**：文件夹权限被收回时，红标 + 系统通知 + Telegram，不再静默停摆。
- **AI 可选**：Kimi 或 OpenRouter 免费模型，失败自动回退付费模型并受每日上限约束。
- 上游核心 84 项、下游扩展 59 项、Agent 86 项测试通过。

- 墨青、纸白、雾青配色及水纹图标，插件入口与工作台统一品牌。
- 主要运行开关集中管理；全文搜索直接使用 Agent 的本机存档配置。
- Telegram 主菜单可新建和删除任务：重复任务跳转、取消输入、删除二次确认和执行回执。
- 回复端只读上游 `_data/` v1 清单及校验后的数据，不重复采集。
- **默认逐条确认**；工作台打开「超时自动发表」后，通知送达 5 分钟无人处理才会尝试发表，点批准即取消倒计时。**提交后不可撤回。**

## 安装

安装 Node.js 24 或以上。本项目无 npm 依赖。在源码根目录执行：

```sh
node scripts/package-local.mjs
```

在 Chrome 扩展管理页开启开发者模式，加载 **`dist/extension`**。源码 `extension` 保留上游基线并逐文件校验，**请加载构建产物，不要直接加载源码目录**（那里没有打下游补丁）。

## 启动与配置

Mac：双击 `agent/启动本地服务.command`。Windows：双击 `agent/启动本地服务.cmd`。也可进入 agent 目录执行 `node server.mjs`。前台启动时窗口需保持打开。

工作台输入 `agent/runtime/pairing-code` 中的本机配对码，随后填写自己的 Kimi API Key 和 Telegram Bot Token，并完成私人账号绑定。凭据只留在本机。默认存档目录为用户下载目录下的 `My0511存档`；自定义目录使用 `agent/runtime/config.json` 的 `archiveDirectory` 字段，保留其中其他设置并重启 Agent。

上游插件负责采集、授权存档文件夹并维护 `_data/`。第一次读取建立基线，不回复旧楼层。任务缺少存档时需在上游补齐，不会重新启动下游采集。

## Telegram

发送 `/menu`：新建任务、删除任务、状态、待审草稿、运行控制和记录。

- 新建：帖子链接 → 当前论坛用户名 → 确认。可发 `/cancel` 取消输入。
- 删除：选择任务 → 核对标题和链接 → 确认。保留存档和已发表回复。
- 发表：查看完整草稿后，一键“批准并加入发帖队列”；批准有效期 24 小时，队列自动等待发表间隔。发送 `/queue` 查看队列。
- 电脑、Chrome 和 Agent 须在线。排队不等于成功，请等待执行回执。

详见 [TG任务管理](docs/TG任务管理_agent14.1.md)。

## 重启与升级

Mac：双击 `agent/重启本地服务.command`。Windows：旧运行窗口按 Ctrl+C 停止，再双击启动脚本。不要同时运行两个 Agent。

升级前备份，覆盖程序文件时**保留自己的 `agent/runtime`**，重新加载 Chrome 扩展并重启 Agent。安装路径和扩展 key 保持不变可保留现有身份。runtime 含密钥和数据库，绝不能上传或分享。

## 验证与限制

发布构建会执行上游核心与下游隔离测试。Mac Chrome 已验证新名称、图标、界面、本机连接及搜索翻页；Telegram 控制逻辑有模拟测试。没有通过真实论坛发帖进行本次验收。Windows 启动脚本尚未真机验证。

纯采集版独立维护，本次不修改。上游机读协议 v1 与公共接口 1.2；随包核心基线 4.2.5，实际本机存档上游为 4.3.2。
